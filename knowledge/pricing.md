# Infeara — Pricing

**Restricted.** This tracked file is a template: all values are `[VERIFY]`. Real figures belong in
`knowledge/local/pricing.md`, which is gitignored. These figures may be quoted only by roles listed in `used_by`, and only when the row
is `verified`. Every price stated to a client must be reproducible from this file.

## Rules

1. A price row is quotable only at `status: verified`.
2. Never quote a single number without the currency, the unit, and what is included.
3. Discounts above the threshold in `discount_authority` require CFO approval in writing.
4. Any price given to a client is logged against the deal in the CRM (once the CRM MCP is live).
5. Public pricing (website) is a separate, approved subset — see `public_pricing_allowed`.
